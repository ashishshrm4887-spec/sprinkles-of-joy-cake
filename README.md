## How to deploy on Vercel (fix the 404 error)

1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New… → Project**
3. Import the repository: `ashishshrm4887-spec/sprinkles-of-joy-cake`
4. **Important settings before Deploy:**
   - Framework Preset: **Other** (or leave blank)
   - Root Directory: `.` (leave empty)
   - Build Command: leave **empty**
   - Output Directory: leave **empty**
5. Click **Deploy**

If you still see 404:
- Go to Project → Settings → General → make sure Framework is “Other”
- Redeploy

After successful deploy you will get a link like:
`https://sprinkles-of-joy-cake.vercel.app`

## Alternative: GitHub Pages (also free)
1. Repo → Settings → Pages
2. Source: Deploy from a branch → `main` → `/ (root)`
3. Save → wait 1 minute
4. Live at: https://ashishshrm4887-spec.github.io/sprinkles-of-joy-cake/
